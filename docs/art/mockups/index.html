Aturan responsif
  • Layout memakai UDim2 skala, bukan posisi piksel tetap.
  • Titik rusak diuji pada lebar 320, 390, dan 430 point, serta rasio 16:9 lanskap.
  • Safe area dari GuiService supaya notch dan home indicator tidak menutup kontrol.
  • Tidak boleh ada overflow horizontal di lebar 320 point.
  • Teks panjang turun baris, tidak dipotong.
State wajib tiap layar
  • Kosong: belum ada clue, meja belum terisi, belum ada pemain.
  • Memuat: memuat kasus, sinkronisasi state dari server.
  • Galat: koneksi putus, kasus gagal dimuat, pemain keluar.
  • Fokus: cincin lampu 3 point, kontras di atas 3:1 di semua latar.
  • Nonaktif: form tuduhan terkunci menampilkan syaratnya, bukan tombol mati.
Yang bukan target sentuh

Chip role dan chip status adalah label, bukan kontrol. Tingginya 26 point dan itu memang disengaja: tidak ada yang bisa ditekan. Yang perlu target sentuh adalah baris yang memuatnya, dan baris itu 62 point.

Aturan pembeda: elemen dengan handler sentuh wajib 44 point atau lebih. Tanpa handler, ukurannya mengikuti tipografi.

Mockup ini statis. Sepuluh tombol di dalamnya menggambar bentuk dan ukuran kontrol, bukan menjalankan aksi. Tidak ada handler dan tidak ada tautan, dan itu disengaja: yang diperiksa di sini adalah tata letak, ukuran target sentuh, dan kontras. Perilaku tiap tombol beserta kelima state layar ada di tabel ui-spec.md bagian 5 dan 7.
